# Xteink Hub

Android app for the Xteink X4 running CrossPoint:

- OPDS server: browse and download on the X4 (File Transfer → OPDS Browser)
- Live sci-fi and science articles, delivered as EPUB digests
- Free public-domain books from Project Gutenberg
- KOReader Sync server for reading progress
- A dashboard with buttons for everything

Every push to `main` builds an APK in GitHub Actions. Get it from **Releases**.
